# Wevva 1.0.0

8 November 2026

Wevva 1.0 marks the start of a dependable application and public-API lifecycle
after a long period of rapid personal-project development. It is not a claim
that every planned feature is finished; it establishes a solid release point
for continuing that development.

## Highlights

- A persistent Dashboard brings the selected forecast, saved locations,
  tropical systems, country alerts, and a Braille world map into one navigation
  hub.
- The full Weather screen now scales from a non-scrolling 80x24 presentation to
  richer wide and tall layouts with hourly/daily forecasts, warning details,
  astronomy, air quality, and interactive country maps.
- The Alerts Centre separates country-wide warning discovery from point alerts,
  with provider documents, warning polygons, searchable lists, cached refreshes,
  and interactive settlement forecasts.
- Tropical Systems has responsive compact and split layouts, canonical storm
  and source tabs, provider tracks and cones, data-backed fix labels, and
  structured Analysis, Forecast, Extents, and official-product views where the
  source supplies them.
- Saved-location, country, alert, tropical, and Dashboard maps share
  collision-aware native callouts and checked-in Natural Earth geography.
- Forecast, warning, bulletin, tropical, and settlement-weather caches reduce
  duplicate work while retaining explicit refresh and stale-result safeguards.
- Search accepts place names or latitude/longitude coordinates, and the setup
  and settings flows persist units, theme, emoji, warning language, defaults,
  and saved locations.

## Python API

The existing synchronous and asynchronous forecast, geocoding, and alert
helpers remain supported. The documented imports from `wevva` continue to be
the public compatibility surface; 1.0 introduces no intentional breaking API
change.

## Dependency baseline

The release locks `wevva-warnings==0.6.0`. That version supplies the canonical
tropical models, structured issuing-centre products, warning-source discovery,
and NHC/CPHC forecast-fix metadata consumed by Wevva.

## Deliberate post-1.0 work

The release does not wait for the optional all-storm tropical overview, generic
map pan/zoom controls, a new focused-alert gazetteer and administrative
hierarchy, warning badges on every location surface, or broader cartographic
layers. These remain valid future improvements rather than release defects.

Publishing, tagging, and package-index availability are intentionally separate
from these notes and happen only after the final release-candidate checks.
