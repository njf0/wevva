# Wevva 1.1.0

18 November 2026

Wevva 1.1 gives new users a populated Dashboard from their first launch and
improves forecast readability, place search, and weather-activity visibility.

## Highlights

- Fresh installations start on the Dashboard with six saved locations:
  Yellowknife, Hilo, Georgetown (Guyana), Accra, Baguio City, and Westport
  (New Zealand). Run `setup` before the first normal launch to accept or
  decline the starters. Existing configurations and caches prevent automatic
  seeding, and deleted starters are not restored.
- Saved locations covered by fresh cached weather warnings now use `!` markers
  on both the Dashboard and full Map View. Warned locations are prioritized in
  the Dashboard's compact world-map sample without starting additional warning
  requests.
- The Dashboard tropical panel and compact tab stay hidden until storms are
  found, giving selected weather alerts the complete detail row during initial
  discovery. Empty results hide the panel again; later refreshes and provider
  failures retain the last trustworthy layout.
- Dashboard forecast tables use content-sized columns, aligned numbers and wind
  directions, and explicit separation between temperature and rain, including
  `100%`. Daily ranges retain their own widths and gain extra breathing room
  when space allows. Daily wind readings remain complete when a forecast
  arrives after layout, and warnings retain the forecast panel's outer padding.
- Place-search results no longer steal focus from the typing input. Keyboard,
  mouse, and coordinate-result selection retain their existing paths.
- The configured default remains pinned on the Dashboard map without becoming
  a saved location, and changing it removes the former default's legacy saved
  copy.
- Dashboard place labels no longer repeat their full location names in hover
  tooltips. Crowded labels can retain the full city name without its temperature
  until enough map space is available for the complete reading.

## Warning dependency

The release pins `wevva-warnings==0.6.1`. Its strict tropical discovery result
distinguishes successful empty activity from required-provider failures, which
allows Wevva to reclaim Dashboard space without hiding uncertain storm state.

## Compatibility

The documented synchronous and asynchronous Python APIs and command-line
options remain available. Existing configurations remain readable; the starter
list is only initialized for profiles without existing configuration or cache
directories. Setting a default location no longer implicitly saves it as an
ordinary location, and replacing a default removes its legacy saved copy.
