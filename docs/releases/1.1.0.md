# Wevva 1.1.0 — draft release notes

Unreleased. The version and release date are not finalized.

Wevva 1.1 makes the post-1.0 Dashboard and location maps more attentive to
current warning and tropical-system activity while keeping their provider work
bounded and cache-aware.

## Highlights

- Saved locations covered by fresh cached weather warnings now use `!` markers
  on both the Dashboard and full Map View. Warned locations are prioritized in
  the Dashboard's compact world-map sample without starting additional warning
  requests.
- After a successful empty tropical-system refresh, the Dashboard hides its
  tropical panel and compact tab and gives selected weather alerts the complete
  detail row. Loading and provider failures retain the last trustworthy layout.
- Compact Dashboard daily forecasts preserve the complete abbreviated date and
  its separation from the condition code.
- The configured default remains pinned on the Dashboard map without becoming
  a saved location, and changing it removes the former default's legacy saved
  copy.
- Dashboard place labels no longer repeat their full location names in hover
  tooltips.

## Warning dependency

The release pins `wevva-warnings==0.6.1`. Its strict tropical discovery result
distinguishes successful empty activity from required-provider failures, which
allows Wevva to reclaim Dashboard space without hiding uncertain storm state.

## Compatibility

This release makes no intentional breaking changes to Wevva's documented
synchronous or asynchronous Python APIs, persisted preferences, or command-line
interface.
